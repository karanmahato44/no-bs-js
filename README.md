# no-bs-js

no bs tiny chromium mv3 userscript runner.

write userscripts in your editor, paste or import them here, done.

## use

```sh
bun install
bun run build
```

load `dist/` as an unpacked extension.

## limits

- local scripts only
- no remote installs
- no script marketplace
- no editor replacement
- only `@grant none`
